エリア管理

草刈りや整備など、エリア維持情報をまとめるページです。

使う機械の写真をタップすると、基本の操作手順を確認できます。

広い場所はタチコマ、タチコマより小回りが必要な場所はるんるん、斜面や物の近くは刈り払い機を使います。

キー

キーボックス内の、虫入りキーホルダーが付いたキーを使います。

右手の操作レバー

左上のスロットルと、右側の大きな赤い変速レバーを使います。下2本のレバーは、どちらも手前に引いてあればOK。勝手に触らないようにします。

足元

前後のアクセルとブレーキペダルです。始動時はブレーキを深く踏みます。

左側の草刈り用レバー

草刈りで使う左側のレバーです。始動時はどちらも手前に来ていることを確認します。

チョーク

エンジンが冷えていて、かかりにくいときに使います。つまみを引くとチョークが開く。エンジンがかかったら状態を見ながら戻します。

始動

右手と左手のレバー位置を確認 → 変速レバーをN → スロットルを低速側 → ブレーキを深く踏む → 必要ならチョーク → キーで始動 → チョークを使った場合は戻す

移動

最初は足をブレーキに乗せたまま、右手の変速レバーで前後操作するのがおすすめです。

障害物が少ない広い場所では、フットペダルのアクセルを使う方が楽な場合があります。

草刈り開始

必ず停車した状態で刃を下ろして回転を始めます。

左側の刈高レバーを80mm〜60mmくらいに合わせる → 赤いレバーを前に倒す → 刃の回転開始

刃を低くしすぎると、地面が緩い場所や凹凸で刃が地面に当たることがあるので注意します。

刃を止める

スロットルをロー → エンジン回転が緩やかになるのを待つ → 赤いレバーをゆっくり手前に引いて停止
ここ大事

高速回転のまま刃を止めない。機械に大きな負担がかかります。

エンジン停止

キーで停止するだけです。

草刈り時の注意
  • 刈った草は右側に排出されるので、排出した草を再び巻き込まないよう、基本は左回りで刈っていきます。
  • 雨の後など、地面が沼状・ぬかるんでいるときは使用しない。
  • 溝・大きな凹凸・斜面に注意する。
  • 刃が停止していても、セーフトーレーンのワイヤーは絶対に跨がない。
  • 作業前にワイヤーの位置を草刈りマップで確認する。
るんるん手押し式草刈機｜端や小回りが必要な場所

始動

ギア「N」→ 出力「ロー」→ 必要ならチョーク → スイッチON → 燃料コックを開く → スターター → チョークを戻す → 出力「ハイ」

移動・草刈り

ギアを入れ、黒いレバーで移動、赤いレバーで刃を回します。左右のレバーを使うと片側の車輪がフリーになり、旋回できます。

草が重いとき

まず移動を止める → 刃を上げて負荷を減らす → 回転が戻ってから続ける

草丈が高いときや濡れているときは、ゆっくり進みます。

終了

移動・刃を止める → エンジン停止 → 燃料コックを閉じる
刈り払い機斜面・物の近く・大型機械が入りにくい場所
›

始動

混合油を確認 → 燃料を送る → 周囲を確認 → スターターを引く

草刈り

装着した状態で安全を確認し、斜面や物の近くなど、大型機械が入りにくい場所を刈ります。

終了

キルスイッチで停止 → 刃が完全に止まったことを確認

このページは京都ハングでの現場確認用の簡易マニュアルです。機体の状態や細かな操作が普段と違う場合は、無理に使用せず確認してください。
