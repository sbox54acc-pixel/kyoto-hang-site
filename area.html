エリア管理

草刈りや整備など、エリア維持情報をまとめるページです。

使う機械の写真をタップすると、基本の操作手順を確認できます。
使い分け
広い場所はタチコマ、タチコマより小回りが必要な場所はるんるん、斜面や物の近くは刈り払い機を使います。
タチコマ乗用草刈機｜広い場所を刈る
›

始動

刃が上がっていることを確認 → 出力「ロー」→ 走行レバー「N」→ ブレーキ → キーで始動
※必要ならチョーク

移動・草刈り

右側のレバーまたはペダルで移動します。最初はブレーキに足を置き、右手のレバーで操作します。左側のレバーで刃を下げ、左手側の操作で刃を回します。

停止

出力を「ロー」→ 刃を止める → キーOFF
注意：セーフトーレーンのワイヤーの上は走行しません。
るんるん手押し式草刈機｜端や小回りが必要な場所
›

始動

ギア「N」→ 出力「ロー」→ 必要ならチョーク → スイッチON → 燃料コックを開く → スターター → チョークを戻す → 出力「ハイ」

移動・草刈り

ギアを入れ、黒いレバーで移動、赤いレバーで刃を回します。左右のレバーを使うと片側の車輪がフリーになり、旋回できます。

草が重いとき

まず移動を止める → 刃を上げて負荷を減らす → 回転が戻ってから続ける

草丈が高いときや濡れているときは、ゆっくり進みます。

終了

移動・刃を止める → エンジン停止 → 燃料コックを閉じる
刈り払い機斜面・物の近く・大型機械が入りにくい場所
›

始動

混合油を確認 → 燃料を送る → 周囲を確認 → スターターを引く

草刈り

装着した状態で安全を確認し、斜面や物の近くなど、大型機械が入りにくい場所を刈ります。

終了

キルスイッチで停止 → 刃が完全に止まったことを確認

このページは京都ハングでの現場確認用の簡易マニュアルです。機体の状態や細かな操作が普段と違う場合は、無理に使用せず確認してください。
