キー

キーボックス内の、虫入りキーホルダーが付いたキーを使います。

右手の操作レバー

左上のスロットルと、右側の大きな赤い変速レバーを使います。下2本のレバーは、どちらも手前に引いてあればOK。勝手に触らないようにします。

足元

前後のアクセルとブレーキペダルです。始動時はブレーキを深く踏みます。

左側の草刈り用レバー

草刈りで使う左側のレバーです。始動時はどちらも手前に来ていることを確認します。

チョーク

エンジンが冷えていて、かかりにくいときに使います。つまみを引くとチョークが開く。エンジンがかかったら状態を見ながら戻します。

始動

右手と左手のレバー位置を確認 → 変速レバーをN → スロットルを低速側 → ブレーキを深く踏む → 必要ならチョーク → キーで始動 → チョークを使った場合は戻す → スロットルをハイ

移動

移動や草刈りをするときは、基本的にスロットルをハイに合わせておきます。

最初は足をブレーキに乗せたまま、右手の変速レバーで前後操作するのがおすすめです。

障害物が少ない広い場所では、フットペダルのアクセルを使う方が楽な場合があります。

草刈り開始

必ず停車した状態で刃を下ろして回転を始めます。

左側の刈高レバーを80mm〜60mmくらいに合わせる → 赤いレバーを前に倒す → 刃の回転開始

刃を低くしすぎると、地面が緩い場所や凹凸で刃が地面に当たることがあるので注意します。

刃を止める

スロットルをロー → エンジン回転が緩やかになるのを待つ → 赤いレバーをゆっくり手前に引いて停止
ここ大事

高速回転のまま刃を止めない。機械に大きな負担がかかります。

エンジン停止

キーで停止するだけです。

草刈り時の注意
  • 刈った草は右側に排出されるので、排出した草を再び巻き込まないよう、基本は左回りで刈っていきます。
  • 雨の後など、地面が沼状・ぬかるんでいるときは使用しない。
  • 溝・大きな凹凸・斜面に注意する。
  • 刃が停止していても、セーフトーレーンのワイヤーは絶対に跨がない。
  • 作業前にワイヤーの位置を草刈りマップで確認する。

停止ボタン・スロットル

赤い停止ボタンを捻って「運転」にし、スロットルがローになっていることを確認します。

ギア

始動前はニュートラル。数字と数字の間にあるNに合わせます。

黒・赤ハンドル

始動前は、左手側の黒い移動ハンドルと右手側の赤い刃回転ハンドルが、どちらも下がっていることを確認します。

ガソリンコック

始動前に、ガソリンコックを横向きの「閉」から、縦向きの「開」にします。

チョーク

写真の針金のような部分がチョークです。エンジンが暖まっていないときに使います。

スターター

スターターを引っ張るとエンジンが始動します。

始動手順

停止ボタンを「運転」 → スロットルはロー → ギアをN → 黒・赤ハンドルが下がっていることを確認 → ガソリンコックを開く → 必要ならチョーク → スターターを引っ張る → 始動したらスロットルをハイ

移動

移動や草刈りをするときは、基本的にスロットルをハイに合わせておきます。

ギアに入れ、左手側の黒いハンドルを上に引き起こすと移動します。最初は1速に入れて操作に慣れます。

左右の操作ハンドルについているレバーを握ると、その側が駆動やブレーキから切り離されます。片側だけ握れば握った側へ曲がり、左右両方を握れば自分の力で押し引きして方向転換できます。

刃を回す・止める

右手側の赤いハンドルを上に引き起こすと刃が回転します。ハンドルを下げると停止します。

操作時の重要事項

刃の回転を始めるとき、またはギアをチェンジするときは、必ず黒い移動ハンドルを下げて停止した状態で行います。

草の抵抗で刃の回転が落ちたとき

移動を停止 → 刃は回転させたまま → るんるんの前方を持ち上げる → 回転速度が戻るのを待つ

草丈が高いときや濡れているときは、無理に進まずゆっくり刈ります。

安全上の注意
  • 大きな石は避ける。事前に取り除く。
  • 刃が回転しているときは、るんるんの前方に立たない。
  • 石などが強い勢いで飛んでくる可能性があります。

エンジン停止

「運転」に合わせていた停止ボタンを押すだけでエンジンが停止します。

停止後はすぐ確認

エンジンを停止したら、すみやかにガソリンコックを横向きの「閉」にします。開けたままだと、現状は燃料が漏れやすくなっています。
