共用アクションカメラ

MOVIO M1034K 4K｜準備・取り付け・撮影・動画の取り込み・片付けまでをまとめています。

1. 撮影前の準備・確認

  • バッテリー残量が十分にあるか確認する
  • 日付・時刻がずれていないか確認する
  • 撮影設定を確認する
  • 取り付け後、撮りたい範囲がカメラの画角に収まっているか確認する
日付表示は基本ON。日時がずれている場合の合わせ方は、今後補助マニュアルとして追加します。

2. グライダーへのセット

  • カメラはテールまたはクロスバーに取り付ける
  • 取り付けベルトを巻き付け、しっかり固定する
  • 落下防止のため、サブの紐も結んでおく
  • 取り付け後、カメラがぐらつかないか確認する
テールに取り付ける場合は、特に落下しないよう念入りに確認してください。
写真を追加予定
テールへの取り付け例 / クロスバーへの取り付け例

3. 撮影のしかた

  1. 前面の電源ボタンを長押しする
  2. 起動音が鳴ったら電源ON
  3. 上部の撮影ボタンを押す → 録画開始
  4. もう一度、上部の撮影ボタンを押す → 録画停止
  5. 録画停止を確認し、前面の電源ボタンを長押しする
  6. 終了音が鳴ったら電源OFF
写真を追加予定
カメラ本体・電源ボタン・撮影ボタン

4. 動画をスマホに取り込む

  1. カメラとスマホを MicroUSB to Type-C ケーブルで接続する
  2. カメラ側にモード選択が表示されたら、外部ストレージとして使う項目を選ぶ
  3. スマホの「ファイル」アプリを開く
  4. カメラ内の動画を開き、必要な部分を2〜3分程度までカットしてからスマホへ保存する
写真を追加予定
USB接続時のモード選択画面 / スマホの「ファイル」アプリ画面
動画の保存には時間がかかります。長い動画はその場で無理に取り込まず、カメラを持ち帰ってPCで取り込むのを推奨します。PCでは MicroUSB to USB ケーブルを使用します。

5. 充電・片付け

  • 使用後は、倉庫のポータブル電源で充電する
  • 用意してある充電ケーブルを使用する
  • 帰る前にポータブル電源から外す
  • カメラとケーブル類は、用意してあるツールボックスに戻す
写真を追加予定
ポータブル電源 / 使用するケーブル / ツールボックス
