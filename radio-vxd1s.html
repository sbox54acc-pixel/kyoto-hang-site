京都ハング / 機材マニュアル

STANDARD VX-D1S
無線機設定マニュアル

初期設定・エリアごとのチャンネル変更・外部スピーカー設定

京都ハングの設定：S4 / UC001
他のエリアでは現地指定のチャンネルとユーザーコードを使用してください。

STEP 1｜スカイチャンネルに設定する

  1. 無線機の電源を切る。
  2. MODEボタンを押しながら電源を入れる。「ピロリロリン」という短い起動音が鳴り、SET MODE と表示された後、C01.CLMOD が表示される。
  3. MODEボタンを何度か押して F01.TXCH を表示する。
  4. ▲▼ボタンで SKY を選択する。
  5. ［MODE］キーを1回押して確定する。
  6. 電源を切り、通常どおり入れ直す。

TX = Transmit（送信）、CH = Channel（チャンネル）。TXCHは送信チャンネル設定。

STEP 2｜チャンネルとユーザーコードを合わせる

  1. 通常どおり電源を入れる。
  2. MODEボタンを長押ししてキーロックを解除する。鍵マークが消えたことを確認する。
  3. ▲▼ボタンでチャンネルを合わせる。京都ハングでは S4。
  4. MODEボタンを押す。UC と3桁の数字が表示される。
  5. ▲▼ボタンを1回押すと、一番左の桁が編集可能になる。
  6. ▲▼ボタンで数字を変更する。
  7. 側面のオレンジ色のボタンで編集する桁を移動する。
  8. 数字変更と桁移動を繰り返し、京都ハングでは UC001 に合わせる。
  9. ［MODE］キーを1回押して確定する。
  10. 通常画面に戻ったら、MODEボタンを長押ししてキーロックをかける。鍵マークが表示されたことを確認する。
注意：UC表示画面は、何もボタンを操作しないと自動的に通常画面へ戻ります。変更する場合は▲▼ボタンを押して編集を開始してください。

UC = User Code（ユーザーコード）。他エリアでは現地指定の値に合わせてください。

STEP 3｜外部スピーカーを設定する

  1. 無線機の電源を切る。
  2. MODEボタンを押しながら電源を入れる。「ピロリロリン」という短い起動音が鳴り、SET MODE の後、C01.CLMOD が表示される。
  3. ［MODE］キーを何度か押して、E-SPK と表示される設定項目を選ぶ。項目番号（F09など）は機種や設定によって異なる場合があるため、E-SPK の表示を目印にする。
  4. ▲▼ボタンで OPT を選択する。
  5. ［MODE］キーを1回押して確定する。
  6. 電源を切り、通常どおり電源を入れ直す。

E = External（外部）、SPK = Speaker（スピーカー）。STD = Standard（標準）、OPT = Option（オプション）。

使用前には現地の指導者の指示に従い、チャンネル・UC・受信状態を確認してください。
